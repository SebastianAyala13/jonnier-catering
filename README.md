# Carta digital — Jonnier Catering

Carta digital estática de Jonnier Catering, con acceso directo a Instagram.

## Publicación

La raíz del repositorio contiene `index.html`, `_headers` y las carpetas de recursos; no requiere instalación ni compilación. Para desplegar en Cloudflare Pages, conecta este repositorio y establece el directorio de salida en `.` (raíz del repositorio), sin comando de compilación.

Instagram: https://www.instagram.com/jonniercatering/
Dominio previsto: https://jonniercatering.com/ (pendiente de vincular y verificar)

## Mantenimiento

Actualiza `index.html` para cambiar contenidos. Conserva las rutas a las carpetas `media`, `marca` y `fuentes`.
